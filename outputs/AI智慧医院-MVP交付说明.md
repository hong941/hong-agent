# AI 智慧医院 MVP 交付说明

## 当前状态

按确认后的“路线 A 智慧医院产品原型”完成第一版可运行 MVP，暂不包含医学影像与虚拟医院模块。项目已跑通“患者预问诊 -> 风险分诊 -> 预约挂号 -> 医生 AI 助手 -> 运营预警”的完整闭环。

![运营端](演示-运营端.png)

## 已实现功能

- 患者端：多轮结构化预问诊、规则 + 模型双通道风险分级、科室推荐、预约挂号。
- 医生端：患者列表、AI 病历摘要、SOAP 草稿、随访计划、知识库检索，输出带引用来源。
- 运营端：候诊队列、科室负载、风险分布、高风险预警、护士人工接管、审计日志。
- 管理端：知识库维护、审计日志、模型与系统状态。
- 平台能力：JWT 登录、RBAC 权限、审计埋点、模型网关、RAG 检索、合成演示数据、免责声明。

## 技术实现

- 前端：React 19 + TypeScript + Vite + Ant Design + ECharts。
- 后端：Python FastAPI + SQLAlchemy + PyJWT。
- 数据：默认 SQLite；`DATABASE_URL` 可切换 PostgreSQL + pgvector，RAG 已实现 BM25 + 向量混合召回。
- AI：兼容 OpenAI 与 Anthropic（DeepSeek）风格的模型网关；配置 API Key 后自动调用真实模型，未配置时使用本地确定性降级引擎，不影响演示。
- 工程化：后端 6 项自动化测试通过，前端 TypeScript 生产构建通过，四个端均通过无头浏览器渲染检查。

## 快速启动

### 后端

```bash
cd backend
python -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 前端

```bash
cd frontend
pnpm install
pnpm dev
```

访问 http://localhost:5173。
